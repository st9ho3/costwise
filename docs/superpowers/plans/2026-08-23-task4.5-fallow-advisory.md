# Task 4.5 — Fallow Advisory Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Authority note (docs/AGENTS.md Delivery Process):** authored by Fable 5; executors implement as written and STOP on anything the plan doesn't cover.
>
> **TDD note:** declared exception (spec, Decision 8) — config files and pure deletions, no new tests. The gates are: existing build + test + lint staying green, and the CI job proving non-blocking on a real PR.
>
> **Executor mode:** External (docs/AGENTS.md, "Executor modes"): push every task-boundary commit with gate output in the commit body and tick this plan's checkboxes in the same commit. This plan has ONE mid-run **⛔ CHECKPOINT** — end of Task 4, before any code is deleted.

**Goal:** Fallow runs as a permanent advisory check (`pnpm fallow` + non-blocking CI job), and the post-Task-4 full pass is triaged: safe deletes committed, judgment items drafted as follow-up tasks, false positives suppressed in config with reasons.

**Architecture:** One pinned root devDependency (`fallow`), one root config (`.fallowrc.json`, JSONC — Fallow auto-detects the pnpm workspaces), two root scripts, one extra job in the existing `ci.yml` that can never fail a PR. ESLint remains the only blocking lint gate.

**Tech Stack:** Fallow (npm `fallow`, MIT), pnpm 11, Turborepo 2, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-23-task4.5-fallow-advisory-design.md`
**ClickUp:** https://app.clickup.com/t/868kv7u7r

## Global Constraints

- Fallow must NEVER block: the new CI job is not a required check, its run step ends `|| true`, and the job carries `continue-on-error: true`. The existing `ci` job is not modified in any way.
- `fallow` is pinned exact (`pnpm add -D -w -E fallow`) — no `^`/`~` range.
- Suppressions live in `.fallowrc.json` with a `-- <reason>` note; inline `fallow-ignore` comments are forbidden in this task.
- Deletions only for findings bucketed **safe delete** in the checkpoint-approved triage table — never from a fresh unreviewed run.
- No refactors: circular deps, deduplication, boundary drift are DRAFTED as tasks, not fixed.
- Work happens on branch `chore/task4.5-fallow-advisory` off up-to-date `main`, in the executor's own checkout/worktree.
- Exact Fallow config key names may differ by version from the examples below. The generated config + `npx fallow --help` / https://fallow.tools/docs are authoritative for SYNTAX; this plan is authoritative for INTENT (what is excluded, what is suppressed, what runs). If intent cannot be expressed with the installed version's config: STOP and report.

- Modify: `docs/where-to-touch.md` (append one section)

**Interfaces:**
- Consumes: `.fallowrc.json` from Task 2.
- Produces: `pnpm fallow`, `pnpm fallow:ci`, CI job `fallow`.

- [ ] **Step 1: Add root scripts**

In root `package.json` `"scripts"`, add exactly:

```json
"fallow": "fallow",
"fallow:ci": "fallow --quiet"
```

(No `dotenv -c` wrapper — Fallow is static analysis and reads no env.)

- [ ] **Step 2: Append the advisory job to `.github/workflows/ci.yml`**

Append under `jobs:` (do not touch the `ci` job):

```yaml
  fallow:
    runs-on: ubuntu-latest
    continue-on-error: true
    steps:
      - uses: actions/checkout@v4

      - uses: pnpm/action-setup@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 24
          cache: pnpm

      - run: pnpm install --frozen-lockfile

      - name: Fallow advisory report (never blocks)
        run: |
          echo '## Fallow advisory findings' >> "$GITHUB_STEP_SUMMARY"
          echo '```'                         >> "$GITHUB_STEP_SUMMARY"
          pnpm --silent fallow:ci | tee -a "$GITHUB_STEP_SUMMARY" || true
          echo '```'                         >> "$GITHUB_STEP_SUMMARY"
```

- [ ] **Step 3: Verify locally**

```bash

pnpm fallow:ci   # quiet variant, exit code irrelevant
```

Expected: both run the pipeline; same findings as Task 2 Step 4.

Append before the "## Rule Of Thumb" section:

```markdown
## Quality Gates

- ESLint — BLOCKING. `pnpm lint`, enforced by the required `ci` job; red blocks merge.
- Fallow — ADVISORY, never blocks. `pnpm fallow` (local/agents) scans the
  monorepo for dead code, duplication, circular deps, and complexity.
  Config: `.fallowrc.json` at repo root — false-positive suppressions go
  THERE, with a reason, never as scattered inline ignores. CI: the
  non-required `fallow` job posts findings to the job summary on every PR.
  Findings triage into cleanup commits or ClickUp tasks (see
  docs/superpowers/specs/2026-08-23-task4.5-fallow-advisory-design.md).
