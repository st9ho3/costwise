Renders a single Lucide glyph at the Costwise stroke weight — the only icon primitive; never inline hand-drawn SVG.

```jsx
<Icon name="receipt-text" size={20} />
<Icon name="trending-down" size={16} color="var(--over)" />
```

Requires the Lucide UMD script on the page: `<script src="https://unpkg.com/lucide@0.454.0/dist/umd/lucide.js"></script>`.
Sizes in use: 16 (inline with text), 20 (buttons, rows), 24 (nav), 32 (empty states).
